Herramienta académica para estimación de volumetría documental en entidades públicas de gran escala, basada en estándares ISO de gestión documental electrónica.

## 🎯 Descripción

Esta calculadora permite estimar el volumen de producción documental diaria, mensual y anual para entidades nacionales con múltiples dependencias y miles de tipologías documentales. Desarrollada siguiendo estándares internacionales ISO 15489, 23081, 16175, 14721 y 30300.

## ✨ Características Principales

- 📈 **Cálculo automatizado** de volumetría documental
- 🏛️ **Diseñada para entidades nacionales** con cientos de dependencias
- 📋 **Basada en TRD** (Tablas de Retención Documental)
- 💾 **Factores de preservación digital** incluidos
- 📊 **Proyecciones a 5 años** con crecimiento configurable
- ⚖️ **Cumplimiento normativo** ISO y legislación colombiana
